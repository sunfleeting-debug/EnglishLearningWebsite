# 句子练习

从导航栏「句子练习」或首页「开始打句子」进入。保持原网站的零构建运行方式，已有启动脚本和双击 `index.html` 均可使用。

## 课程和练习

内置 6 门原创课程，A1、A2、B1 各 2 门，每门 8 组，每组 3 步，共 48 组 / 144 个步骤。

| 方式 | 行为 |
| --- | --- |
| 递进练习 | 同一组从短语或短句开始，逐步写到完整句；显示上一小步帮助连接表达 |
| 整句翻译 | 只练每组最后的完整句，看中文输入英文 |
| 听音写句 | 只练完整句，以音频为题面；可重听或查看答案 |

练习中切换方式会保留当前组，清空该步输入，从对应方式重新练；已经记账的组不会重复增加完成数。每组的答错、提示记录会保留，不能通过切换方式把辅助练习变为独立答对。

提交后会定位首个错词，输入中正确部分保留；可以直接修改选中的词。格式容错包含大小写、空白和常见标点，词序、拼写和词形仍需正确。课程可以声明 `alternatives` 作为等价答案，页面会按匹配的答案给出反馈。没有使用 AI 翻译或自由语义评分。

## 键盘和发音

| 按键 | 作用 |
| --- | --- |
| Enter | 检查答案；答对反馈后进入下一小步 / 下一组 |
| Alt + S | 朗读 / 重听 |
| Alt + H | 显示 / 收起答案 |
| Alt + F | 收藏 / 取消收藏 |
| Alt + 1 / 2 / 3 | 切换递进 / 整句 / 听写 |
| Esc | 保存当前会话并返回课程 |

输入法正在组字时 Enter 不会误提交。手机可直接点检查、提示和播放按钮。

发音沿用网站的「在线音频 → 系统语音兜底」，口音和发音通道由设置页控制。「答对后自动朗读」可在句子课程页的练习偏好中关闭。音频不可用时仍可使用中文题面与键入练习。

## 错句、收藏和统计

- 首次出错、查看答案或自动显示无中文素材的英文时，即加入待攻克与当天复习；即使退出并打开另一门课，这条记录也会保留。
- 一组完整做完才增加一次完成数；三步递进不会计成三组。重按 Enter、同组重练或切换方式不会重复记账。
- 该组任何一步出错或获得答案帮助，完成结果记为需要再练。之后独立答对清除待攻克，并把已有队列的下一次复习推到 1 / 2 / 4 / 7 / 15 / 30 / 60 天。
- 收藏独立于复习，取消收藏不会删除学习记录。收藏和已练列表会逐批覆盖全部句子，覆盖完后可重新开始一轮。
- 句子统计和单词统计分开，首页、复习页、学习统计页均有句子入口。

## 导入自己的课程

进入「导入课程」，粘贴内容或选择文件，然后「预览课程 → 确认加入课程」。确认前不会修改课程和进度。

最简单的中英句对，每行一组：

```text
I read every day. | 我每天阅读。
Could you help me? | 你能帮帮我吗？
```

CSV / TSV 支持 `en,zh`、`english,chinese` 或「英文,中文」等列名；含逗号或换行的字段需按 CSV 规则使用双引号。也支持交替中英两行和纯英文文章。

SRT / VTT 字幕会过滤序号、时间码、注释与字幕标签，按字幕块提取英语和对应中文。无中文素材显示英文供跟打，并计为辅助练习；不会凭空翻译。当前不做音视频文件的语音识别，请先导出字幕。

需要自己编排递进步骤时，导入 JSON：

```json
{
  "title": "我的阅读表达",
  "level": "A1",
  "units": [{
    "title": "每天阅读",
    "steps": [
      { "en": "I read.", "zh": "我阅读。" },
      { "en": "I read a book.", "zh": "我读一本书。" },
      { "en": "I read a book every day.", "zh": "我每天读一本书。",
        "alternatives": ["Every day I read a book."] }
    ]
  }]
}
```

导入页面也可下载示例。每课最多 300 组、每组最多 15 步、最多 50 门自定义课程及 2000 组自定义句子；解析内容最多 1 MB。错误文件会报告原因并保留现有数据。自定义课程可以在课程卡上导出或删除。

## 保存和备份

句子使用独立浏览器键 `typingcet.sentences.v1`，与旧的 `typingcet.state.v1` 单词数据分开。当前云同步接口没有增加句子字段；登录账号不会把句子记录上传。页面明确显示此保存范围。

设置页「导出备份」会把句子状态放进总备份的 `sentences` 字段；「导入备份」可以恢复课程、进度、收藏、复习和当前会话。没有 `sentences` 字段的旧备份仍可使用，并保留现有句子数据。「清空学习记录」会清空句子练习状态，但保留导入的课程。

## 核验

核心逻辑不需要外部依赖：

```powershell
node tools/test_sentences.cjs
```

浏览器核验使用已有本机测试环境：

```powershell
$env:PYTHONIOENCODING = 'utf-8'
$env:PLAYWRIGHT_BROWSERS_PATH = "$PWD\tools\.cache\ms-playwright"
& .\tools\.cache\venv\Scripts\python.exe tools/verify_sentences.py
```

脚本启动独立随机端口服务器，使用临时浏览器 Context，不访问日常浏览器配置；截图、断言结果和日志位于 `tools/.cache/sentence-verification/`。

本次已验证：17 组核心逻辑测试、198 项句子浏览器断言、172 项原网站回归均通过；桌面、390px 手机、深色主题及 `file://` 刷新续学已检查。额外验证了真实在线短语音频加载、完整句调用系统语音回退，以及音频失败回退。系统语音是否实际发声仍取决于浏览器和设备上的英语语音引擎，可在设置页调整发音通道。

参考项目：[Earthworm](https://github.com/cuixueshe/earthworm)。本功能的代码、课程和固定间隔复习逻辑为本站独立实现；仅参考其递进句子输入的交互方式。
